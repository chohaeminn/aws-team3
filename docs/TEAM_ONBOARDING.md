# 팀원 공유용 안내

현재 도쿄 리전 EC2에 배포되어 Cognito 로그인과 Bedrock 실제 분석을 확인했습니다. DynamoDB 전환은 코드 병합 후 배포 대기입니다. 최신 상태는 [변경 기록](CHANGELOG.md), 배포 절차는 [AWS 배포 안내](AWS_DEPLOYMENT.md)를 확인해주세요. 아래의 초기 역할·시간표는 기획 당시 안내입니다. 최신 실행·배포·시연 확인은 [통합 체크리스트](DEMO_CHECKLIST.md)와 [작업 현황 #18](https://github.com/chohaeminn/aws-team3/issues/18)을 확인해주세요.

아래 내용을 팀 채팅에 복사해서 공유하면 됩니다.

---

우리 팀 **결제 취소·환불 추적 서비스** 저장소와 협업 안내입니다.

- 저장소·서비스 기획: https://github.com/chohaeminn/aws-team3
- 협업 규칙: https://github.com/chohaeminn/aws-team3/blob/main/CONTRIBUTING.md
- 작업·오류 이슈 생성: https://github.com/chohaeminn/aws-team3/issues/new/choose
- PR 목록: https://github.com/chohaeminn/aws-team3/pulls

**오늘 목표:** 합성 결제 3건과 전액 취소 흐름을 구현합니다.

**대표 시연:** 취소 증빙 입력 → AI 추출 → 고객 수정·확인 → 결제 연결 → ‘가맹점 취소 확인 / 카드 반영 미확인’ 표시 → 문의자료 복사.

**역할:** ① 결제 데이터·API ② AI 증빙 분석 ③ 상태 판단·문의자료 ④ UI·시연 연결. 각자 담당 이슈를 만들고 Assignees에 본인을 지정해주세요.

**작업 순서**

1. 이슈 템플릿으로 목표·완료 기준·선행 작업 작성
2. 최신 `main`에서 `feat/이슈번호-작업명` 브랜치 생성
3. 작업 후 Draft PR로 공유, 본문에 `Closes #이슈번호`와 검증 결과 작성
4. 준비되면 리뷰어 1명 지정 → 승인·수정 반영 → Squash and merge

커밋·PR 제목 예시: `feat: 취소 증빙 항목 추출 구현`

첫 30분에 API·타입·오류 형식과 Bedrock 권한을 확인하고, 2시간 30분부터 대표 거래 1건을 통합합니다. 막힌 점이나 API 변경은 이슈 댓글에 바로 남겨주세요.

가맹점 취소와 카드 반영은 별도로 표시합니다. 취소 메일만으로 환불 완료를 판단하지 않고, AI 결과는 고객 확인 후 연결합니다. 실제 AI 호출과 예시 응답은 구분하고, 합성 데이터만 사용합니다.

현재 저장소의 구현 상태는 README를 확인해주세요. AWS 키·`.env`·실제 고객 정보는 업로드하지 않습니다.

## 시작할 작업 예시

아래는 실제 이슈 생성 전 분담을 위한 예시입니다. 담당자와 완료 기준을 확정한 뒤 이슈로 등록합니다.

| 작업 | 완료 기준 | 선행 작업 |
| --- | --- | --- |
| API·공유 타입 합의 | 거래·증빙·금액·통화·날짜·상태·오류 예시 합의 | 없음 |
| Bedrock 호출 확인 | 합성 증빙 1건의 실제 호출 성공 결과 기록 | AWS 계정·권한 |
| 합성 결제 3건·조회 API | 합의된 응답으로 세 거래 조회 | API 합의 |
| 증빙 추출·후보 제시 | 추출 실패 재시도와 후보 표시 확인 | API 합의·Bedrock |
| 상태·문의자료 | 가맹점·카드 상태 구분과 복사할 요약 확인 | API 합의 |
| 고객 확인 UI·통합 | 수정·확인 후 연결, 상태 표시, 요약 복사 | API·AI·상태 |
| 배포·시연 검증 | 다른 PC 접속, 초기화, 실제 측정 결과 기록 | 대표 흐름 통합 |
