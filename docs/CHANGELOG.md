# 변경 기록

## 2026-11-27 — AWS 전환 (도쿄 리전)

로컬 MVP를 AWS(도쿄 `ap-northeast-1`)에서 동작하는 시연 프로토타입으로 옮겼습니다.
- 로그인: Amazon Cognito
- AI 분석: Amazon Bedrock
- 저장: Amazon DynamoDB. 이전 SQLite에서 전환했습니다.

여전히 합성 결제 3건의 원화 전액 취소만 다루며, 실제 카드사와는 연동하지 않습니다.

### 현재 AWS 상태 (2026-11-27 KST 기준)

| 항목 | 상태 | 근거 |
| --- | --- | --- |
| 실행 중인 앱 | `393ec7b` (#28·#30·#36~#39 포함). 단일 EC2, 공개 포트 없음, SSM 포트 포워딩으로 접속 | [배포 실행](https://github.com/chohaeminn/aws-team3/actions/runs/46010186206) |
| 로그인 | Cognito Hosted UI (Authorization Code + PKCE). 관리자는 `refund-demo-admin` 그룹 | 실제 로그인 확인 |
| AI 분석 | Bedrock `apac.amazon.nova-lite-v1:0`. EC2 IAM 역할로 호출하며 API 키는 쓰지 않음 | 실제 호출 확인 ([시연 체크리스트](DEMO_CHECKLIST.md)) |
| 저장소 | **Amazon DynamoDB** (`PAYMENT_STORE=dynamodb`). 온디맨드, 시점 복구, 암호화 | 서버 설정 확인 |
| 소유권 이관 | 배포 때 SQLite의 결제 3건 소유권을 DynamoDB로 자동 이관 (3/3 배정) | 테이블 조회 |

이전 SQLite 파일은 지우지 않고 남겨 두었습니다(되돌리기용).

되돌리려면 `aws-demo` 변수 `PAYMENT_TABLE`을 비우고 다시 배포합니다. 자세한 내용은 [DynamoDB 문서](DYNAMODB.md#도쿄-데모-스택-전환과-복구-35)를 봅니다.

### 개발·운영 변경

- **CI:**
  - Node.js 22.18.0과 24에서 타입 검사, 빌드, 테스트, 셸 구문 검사, CloudFormation lint를 실행합니다.
  - DynamoDB Local 계약 테스트를 별도 작업으로 추가했습니다(#39).
- **CD:** `Deploy AWS demo`를 `main`에서 수동으로 실행합니다.
  - 같은 실행에서 검증한 아티팩트만 배포합니다.
  - AWS 인증은 GitHub OIDC 임시 자격 증명을 씁니다. 장기 액세스 키는 쓰지 않습니다.
- **의존성:** `@aws-sdk/client-dynamodb`, `@aws-sdk/lib-dynamodb`를 추가했습니다.
  - CI의 `npm ci`가 통과하도록 lockfile을 npm 10 기준으로 다시 만들었습니다.
